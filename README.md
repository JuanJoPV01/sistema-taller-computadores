# Sistema de gestión de reparaciones - Taller de computadores

Solución de la **Actividad de Aprendizaje de la Unidad 2** de
**Estructuras de Datos**: un sistema de consola en Java que administra
equipos recibidos en un taller de computadores usando una **lista**, una
**cola** y una **pila** implementadas manualmente con nodos enlazados.
